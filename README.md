# PlayWright3x JavaScript Practice

This repository is a JavaScript learning and practice workspace built around core fundamentals, problem-solving exercises, and asynchronous programming concepts. Although the repo name includes Playwright, the current material focuses on JavaScript fundamentals rather than browser automation.

## Overview

The goal of this repository is to help build confidence in JavaScript by practicing:

- Variables, values, and data types
- Operators and comparisons
- Conditional logic and switch statements
- Loops and iteration patterns
- Arrays and array operations
- Functions, closures, and hoisting concepts
- Strings and objects
- Callback functions and higher-order patterns
- Promises and async/await
- Classes, objects, static members, and OOP concepts
- Interview-style JavaScript questions and notes

## Prerequisites

- [Node.js](https://nodejs.org/) installed
- A code editor such as [Visual Studio Code](https://code.visualstudio.com/)

## Run examples

From the repository root, you can run a script like this:

```bash
node 18_chapter_Async_Await/02_better_way.js
```

For scripts that read input from the terminal, use the Node.js REPL-style input flow in the terminal. On Windows, you may need to press `Ctrl + Z` and then `Enter` to finish input.

## How to use this repo

1. Open a JavaScript file in VS Code.
2. Read the concept and example.
3. Execute it with Node.js.
4. Modify the code and practice variations.
5. Revisit the notes and challenge files to strengthen understanding.
